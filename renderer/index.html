Settings

Blocked sites (Secure DNS)

Encrypts DNS lookups so DNS-level blocks can't see or block the sites you visit. Secure mode sends DNS to Cloudflare or Google instead of your ISP.

Changing Secure DNS needs a browser restart to take effect.

Proxy

Route traffic through a proxy server. Applies immediately — no restart needed.

SOCKS proxies work too: socks5://127.0.0.1:1080. For a proxy that needs a username and password, fill these in (stored in this computer's settings file — see README).

Free VPN

Routes your traffic through a free public server so blocked sites open and your location looks like the server's country. Servers are volunteers' public proxies from GeoNode's free list — no account, no key.

Honest warning: free servers are slow, they come and go, and a free server can see your traffic — use it for unblocking sites and casual browsing only, never for banking, passwords, or sensitive logins.

VPN is off.

AdBlocker

Blocks ads and trackers on every page (EasyList). On by default. Some sites ask you to turn your blocker off — use "Allow ads on this site" for those, instead of turning blocking off everywhere.

Tabs & Reading

Sleeping tabs free their memory and reload when clicked. Tabs playing audio never sleep.

AI Assistant (Google Gemini)

The AI panel uses Google Gemini with your own free API key from Google AI Studio. The key is stored only on this computer and sent only to Google's Gemini API — never anywhere else. No key is built into the browser.

On Google's free tier, content you send may be used to improve Google's products — don't paste passwords or private data. Chat history is session-only and never saved.

Extensions

Load Chrome extensions from an unpacked folder or a .crx file. Extensions run in normal windows only. Chrome Web Store one-click install does not work in this browser — download the .crx or the unpacked extension first.
